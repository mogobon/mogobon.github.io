# ABC C/D 200問カード — PWAとオフライン同期

## 使用方法
1. iPhoneのSafariで https://mogobon.github.io/abc_cd_cards.html を開き、一度オンラインでページを読み込む。
2. Safariの共有メニューから「ホーム画面に追加」。ホーム画面の「ABC C/D」を起動する。
3. 一度インストール・キャッシュが完了すれば、200問の問題文・個人メモ・要約の編集をオフラインで利用できる。
4. GitHub同期を使う場合はアプリ内の「GitHub同期を設定」でPATを登録する。オフライン中の要約編集はローカル下書きに保持し、オンライン復帰時に同期を再開する。
5. iOSのホーム画面アプリではSafariと保存領域が別になる場合があるため、必要に応じてPATをアプリ側でも設定する。

## オフライン保存
- `abc_cd_sw.js` が200問を含むHTML、同期JS、一覧、manifest、アイコンをキャッシュする。
- GitHub APIの結果をService Workerでキャッシュしない（競合判定を維持する）。
- 最後に取得した同期済みの要約は `abc-cd-summary-remote-cache-v1` としてlocalStorageに控える。
- 未同期の編集は既存の `abc-cd-summary-drafts-v1` に残す。
- Safari / iOSがストレージを消去した場合はオフライン利用も未同期下書きも保持されない。必要な編集はオンラインでGitHubに同期すること。
- MathJax本体を可能なら事前キャッシュする。未取得の追加フォントなどはオフラインで欠ける場合がある。

## GitHub PATの接続保持
- 標準: メモリ保持のみ。セッション保持チェックでsessionStorage。
- 任意: 「この端末に接続を保持」を選ぶとPATをlocalStorageに保存し、再起動後も自動同期できる。
- **注意:** localStorageに保存したPATは同一オリジン上のJavaScriptから読める。共有端末では利用しない。不要なら接続解除。
- 内容は公開GitHubリポジトリのJSONに保存される。学習メモと理解度は端末ローカルのまま。

## 操作
- 表面タップ: 裏返す。
- 裏面の入力欄以外をタップ: 表面へ。
- カードを左右にスワイプ: 前後のカードに移動。
- 入力欄操作・要約編集中・縦スクロール時にはスワイプ移動を抑制。

## テスト手順
- オンライン初回アクセス後、ホーム画面に追加して単独起動できるか。
- 機内モードでカードを更新・前後移動・個人メモを保存できるか。
- 機内モードで要約を編集し未同期件数が残るか。
- オンライン復帰後、PATの接続が有効ならGitHubへの同期が完了するか。
- 別端末から変更を読み込めるか。同じ要約を同時に編集した場合に競合表示されるか。

## 補足
Service Workerのスコープはサイトルート（`/`）で、カードに関連する既知パスだけをキャッシュする。他のGitHub Pagesの機能への影響を避ける。
